# 이미지 가이드 (스타건설 — 샷시 손잡이 교체)

현재 모든 이미지는 스타건설 블로그(blog.naver.com/hongstarhome) 실제 시공사례 사진으로 채워져 있습니다.

## 교체하면 좋은 이미지

- `hero.jpg` (2400×1350, 16:9) — 현재 KCC 손잡이 사진을 임시로 재활용 중. 전용 이미지로 교체 권장.
  - 프롬프트는 대화 기록 참고: 검정 알루미늄 손잡이 클로즈업, 왼쪽 40%는 텍스트 얹힐 단순한 창틀 면.

## 시공사례 (교체 시 같은 파일명으로 덮어쓰기)

- `case-01-*` : 동탄 반도유보라 LX샷시 손잡이 교체
- `case-02-*` : 한화 샷시 손잡이 호환품 교체
- `case-03-*` : 관악구 영림샷시 로드 교체
- `case-04-*` : KCC 샷시손잡이 락킹기어 교체

원본 사진은 `_raw/` 폴더에 있습니다 (배포 제외, `.gitignore` 처리됨).
새 사례를 추가하려면 `tools/fetch-blog-post.py <블로그글주소> <저장폴더명>`으로 다운로드하세요.
